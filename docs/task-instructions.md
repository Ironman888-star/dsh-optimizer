# 任务指令改写 / Editable task instructions

设置 → 智能优化管家 →「任务指令改写」支持编辑/保存/恢复预置。用户保存的 `taskInstructions.text` 写入本地 `config.json`。插件使用 DSH 的 `systemPrompt.section()` 注册该文本，并在之后的提示词组装时读取当前保存值。

- 输入上限为 **12,000 字符**，不要输入账户密钥、密码或私人消息；此文本可能随 DSH 正常模型请求送至模型服务商。
- 已保存的指令应在下次请求中看到；若宿主的某种路由覆盖所有系统提示词，则应单独检查是否包含它。
- 指令为**模型行为建议**，不能强制禁止文件扫描，也不是账户权限验证。
- 公开源码预置文本使用连续编号 `1–5`，只规范默认编号、不改指令语义；用户可以自行编辑，已持久化的个人设置仍优先于默认值。
- 「恢复预置」把默认内容放回编辑框；需要保存后才会成为后续请求采用的文本。

完整配置参见 [配置](configuration.md)。
